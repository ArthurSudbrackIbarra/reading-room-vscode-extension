The translate tool of Reading Room is built from these parts.

In this folder
--------------

bergamot-translator-worker.js, bergamot-translator-worker.wasm
  Bergamot Translator: the translation engine, built to WebAssembly. Unmodified, as published in
  the npm package @browsermt/bergamot-translator 0.4.9.
  License: Mozilla Public License 2.0 (https://www.mozilla.org/MPL/2.0/)
  Source code: https://github.com/browsermt/bergamot-translator

worker.js
  Code of Reading Room (MIT), bundled with two libraries that tell which language a text is in:
  - franc 6.2.0, by Titus Wormer and contributors. MIT License. https://github.com/wooorm/franc
  - tinyld 1.3.4, by Kevin Destrem. MIT License. https://github.com/komodojp/tinyld

models.json
  The list of language packs the tool offers: where their files are, and what they are checked
  against. Made from Mozilla's list of translation models.

Downloaded when you ask for them
--------------------------------

Language packs
  The translation models Mozilla trains for Firefox's translation of web pages
  (https://github.com/mozilla/translations). They are not part of this extension: a pack is
  downloaded from Mozilla's storage, after you agreed to it, into VS Code's storage for this
  extension.
